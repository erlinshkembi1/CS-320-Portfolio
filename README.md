# CS-320 Portfolio

CS-320 Software Testing, Automation, and Quality Assurance Portfolio

## Portfolio Reflection

### How can I ensure my code, program, or software is functional and secure?

To make sure my software works correctly, I need to test it carefully and check for errors. In this course, I learned how to use JUnit testing to check if my code meets the requirements. I also learned that testing both valid and invalid inputs is important because it helps prevent unexpected problems. For security, I believe validating user inputs and handling errors correctly can help make software safer and more reliable.

### How do I interpret user needs and incorporate them into a program?

I start by understanding what the user needs and what the program is supposed to do. Then I turn those needs into requirements that I can follow when writing my code. For example, in the contact service project, I had to make sure users could add, update, and delete contacts while following specific rules. Testing helped me confirm that these features worked correctly.

### How do I approach designing software?

When designing software, I try to keep my code simple, organized, and easy to understand. I like to break bigger problems into smaller parts so they are easier to manage. I also think about testing while developing the program instead of waiting until the end. This course taught me that good software design is not only about making a program work but also making sure it is reliable, secure, and easy to maintain.
